# Electronic Circuit Schematics

## Overview

This section documents the electronic design developed using EasyEda.

The system integrates two sensing subsystems for fetal movement detection and fetal heart rate (FHR) monitoring.

## Main Components

### 1. Fetal Movement Detection
- **Accelerometers:** Six-axis inertial measurement unit (accelerometer and gyroscope).
- **I²C Communication:** Digital data transmission between the MPU6050 and ESP32.

### 2. Fetal Heart Rate Monitoring
- **Piezoelectric Sensor:** Detects mechanical vibrations potentially associated with fetal cardiac activity.
- **Protection Circuit:** Limits excessive voltage generated by the piezoelectric sensor.
- **Operational Amplifiers:** Amplify the acquired analog signal.
- **Analog Filters:** Reduce unwanted noise and frequency components.
- **ESP32 ADC:** Converts the conditioned analog signal into digital data for processing.

### 3. Processing Unit
- **ESP32 Microcontroller:** Acquires and processes data from both sensing subsystems.
